# Language Echo

Language Echo is a dynamic, audio-focused language learning application currently containing curated listening modules for Mandarin, Spanish (for English speakers), and English (for Spanish speakers). The application provides an engaging and responsive UI where users can actively listen, read, and retain core vocabulary from real-life scenarios.

## Features

- **Multi-language Support:** Choose from curated modules for Mandarin, English, and Spanish.
- **Interactive Listening:** High-quality Text-To-Speech audio mimicking real-life interactions.
- **Dynamic Comprehension:** Listen to sentences at native speed, analyze interactive sentence breakdowns, and test your understanding with comprehension questions.
- **Vocabulary Tracking:** Save words you don't know and review them in a clean, language-specific vocabulary interface.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Running Locally

1. Clone this repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Design

Built with modern web design principles including glassmorphism, responsive layouts, and smooth micro-animations to create a premium, "wow" user experience.
